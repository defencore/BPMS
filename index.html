Wi-Fi module setup

The device supports these Wi-Fi commands:

  • 0xA0 - Set the router SSID and password
  • 0xA1 - Connection interval (1–120 min)
  • 0xA2 - Server address and port
  • 0xA3 - IP settings (DHCP/static)
  • 0xA4 - Get the IP configuration
  • 0xA5 - SSID for AP mode (12 characters)
  • 0xA6 - Get the MAC address
  • 0xA7 - Reset the Wi-Fi module
  • 0xA8 - STA mode (operating mode)
  • 0xAF - Sleep interval (5–100 sec)
  • 0xC5 - Get the device code
  • 0xCC - Blind measurement mode

Note: Some commands may require a special device mode

Session identification

WBP-02A exposes the patient name and numeric session ID through separate USB commands.

  • The patient name is UTF-8 text with a 32-byte device limit
  • The session ID is a 32-bit little-endian integer
  • BPMS reads both values from the device and includes them in exports
Verified commands: 0x41/0x55 write/read the patient name; 0x42/0x56 write/read the numeric ID.
